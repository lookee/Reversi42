## Quick Start

1. **Fork and clone** the repository
2. **Set up** your environment (see [Development Setup](development-setup.md))
3. **Create a branch** for your changes
4. **Make your changes** following our [Code Style Guide](code-style.md)
5. **Write tests** (see [Testing Guide](testing.md))
6. **Submit a PR** (see [PR Process](pull-request-process.md))

## Contribution Types

### 🐛 Bug Fixes
- Find bugs in [Issues](https://github.com/lookee/Reversi42/issues?q=is%3Aissue+is%3Aopen+label%3Abug)
- Reproduce the bug locally
- Write a failing test
- Fix the bug
- Ensure all tests pass
- Submit PR

### ✨ New Features
- Discuss in [Discussions](https://github.com/lookee/Reversi42/discussions) first
- Get approval from maintainers
- Follow [Feature Development Guide](feature-development.md)
- Include comprehensive tests
- Update documentation

### 📚 Documentation
- Fix typos and improve clarity
- Add missing documentation
- Create tutorials and examples
- Update API references
- No approval needed for typos!

### 🎨 UI/UX Improvements
- Discuss design changes first
- Provide mockups if possible
- Ensure accessibility
- Test on multiple platforms

### ⚡ Performance Improvements
- Benchmark before and after
- Include performance tests
- Document the optimization
- Explain trade-offs

## Development Workflow

```
1. Fork repository
       ↓
2. Clone your fork
       ↓
3. Create feature branch
       ↓
4. Make changes
       ↓
5. Run tests locally
       ↓
6. Commit changes
       ↓
7. Push to your fork
       ↓
8. Open Pull Request
       ↓
9. Address review feedback
       ↓
10. Get merged! 🎉
```
